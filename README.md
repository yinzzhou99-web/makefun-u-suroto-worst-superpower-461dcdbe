**Worst Superpower** — exactly one line, at most 140 characters, inventing a superpower and making plain why it is useless. The power is genuinely pointless, and the joke is picturing it in use: "My superpower: I can hear what dogs are thinking, but only on Tuesdays — and they are all thinking about the same squirrel."

## Run it

```sh
python3 main.py
```

`main.py` (standard library only, no network) writes the line to `/output/entry.txt` and checks it against the gate (1–140 chars).
